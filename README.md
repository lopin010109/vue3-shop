# Vue3 Shop

使用 Vue 3 + TypeScript 開發的電商購物網站練習專案，
用於學習 Composition API、Pinia 狀態管理與多語系實作。

## Demo
https://vue3-shop-eosin.vercel.app/

## 技術棧
- Vue 3 (Composition API)
- TypeScript
- Vite
- Pinia（狀態管理）
- Vue Router
- Element Plus
- vue-i18n（多語系）
- Axios
- SCSS
- 部署：Vercel

## 功能
- 商品列表瀏覽
- 購物車
- 多語系切換
